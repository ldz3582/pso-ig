## 1. 问题描述

### 1.1 问题定义

混合流水车间调度问题（Hybrid Flow Shop Scheduling Problem, HFSP）是一个经典的组合优化问题。

**问题描述**：
- 有 `n` 个工件需要在 `c` 个阶段上加工
- 每个阶段有 `m_i` 台并行机器（可以同时加工不同的工件）
- 每个工件必须按顺序经过所有阶段
- 同一工件在不同阶段的加工时间可能不同
- 目标是最小化最大完工时间（Makespan）

### 1.2 数学模型

#### 决策变量

```
x_jk = 工件 j 在阶段 k 的开始时间
y_jkm = 工件 j 是否在机器 m 上加工（1 是，0 否）
C_max = 最大完工时间
```

#### 目标函数

```
minimize C_max
```

#### 约束条件

1. **工序顺序约束**：
   ```
   x_j(k+1) ≥ x_jk + p_jk    ∀j, k=1,...,c-1
   ```
   工件 j 在阶段 k+1 的开始时间必须大于等于在阶段 k 的完成时间

2. **机器容量约束**：
   ```
   x_jkm ≥ x_j(k-1)m + p_j(k-1)m    ∀j, k=2,...,c, m=1,...,m_k
   ```
   工件 j 在机器 m 上的开始时间必须大于等于在前一阶段同一机器上的完成时间

3. **机器互斥约束**：
   ```
   x_jkm + p_jkm ≤ x_lkm + M(1 - z_jlkm)    ∀j<l, m=1,...,m_k
   x_lkm + p_lkm ≤ x_jkm + M*z_jlkm
   ```
   同一机器上不能同时加工两个工件

4. **完工时间约束**：
   ```
   C_max ≥ x_jc + p_jc    ∀j
   ```
   最大完工时间必须大于等于所有工件的完成时间

### 1.3 复杂度分析

- **时间复杂度**：NP-hard 问题
- **空间复杂度**：O(n*c*m)

## 2. 算法设计

### 2.1 核心算法

#### NEH 启发式算法

**目的**：生成高质量的初始解

**算法步骤**：

1. **计算总加工时间**：
   ```
   T_j = Σ_k (Σ_m p_jkm / m_k)    ∀j
   ```
   计算每个工件在所有阶段的平均加工时间

2. **降序排序**：
   ```
   T_1 ≥ T_2 ≥ ... ≥ T_n
   ```
   按总加工时间降序排列工件

3. **插入最优位置**：
   ```
   for j in sorted_jobs:
       for pos in 0..len(current):
           new_perm = current[:pos] + [j] + current[pos:]
           makespan = evaluate(new_perm)
           if makespan < best:
               best = makespan, best_pos = pos
       current = current[:best_pos] + [j] + current[best_pos:]
   ```

**时间复杂度**：O(n² * c * m)

#### 小生境 PSO 算法

**目的**：全局搜索，维持多样性

**核心机制**：

1. **粒子表示**：
   ```
   粒子 = (position, velocity, personal_best)
   position = [j_1, j_2, ..., j_n]    # 工件排列
   velocity = [v_1, v_2, ..., v_n]    # 速度（用于更新）
   ```

2. **速度更新**：
   ```
   v_id = w * v_id + c1 * r1 * (pbest_id - x_id) + c2 * r2 * (lbest_id - x_id)
   ```
   - `w`：惯性权重（自适应）
   - `c1`：个体学习因子
   - `c2`：社会学习因子
   - `r1, r2`：随机数

3. **位置更新**：
   ```
   position = position + velocity
   ```
   使用交换操作更新排列

4. **自适应权重**：
   ```
   w = w_max - (w_max - w_min) * (gen / max_gen)
   ```
   - 早期：大权重（全局搜索）
   - 后期：小权重（局部搜索）

5. **环形拓扑**：
   ```
   每个粒子只与左右 k 个邻居交互
   ```

6. **停滞检测**：
   ```
   if 连续 T 代无改进:
       重新初始化 20% 的种群
   ```

**时间复杂度**：O(G * n * log(n))

#### 迭代贪婪 (IG) 算法

**目的**：局部深挖，跳出局部最优

**核心机制**：

1. **破坏阶段**：
   ```
   destroyed_jobs = random_select(jobs, ratio=30%)
   remaining_jobs = jobs - destroyed_jobs
   ```

2. **重建阶段**：
   ```
   for job in destroyed_jobs:
       for pos in 0..len(remaining):
           candidate = remaining[:pos] + [job] + remaining[pos:]
           makespan = evaluate(candidate)
           if makespan < best:
               best = makespan, best_pos = pos
       remaining = remaining[:best_pos] + [job] + remaining[best_pos:]
   ```

3. **接受准则**：
   ```
   if new_makespan <= current_makespan:
       accept
   else if exp(-(new - current) / T) > random():
       accept
   ```

**时间复杂度**：O(I * n²)

### 2.2 组合策略

```
NEH + PSO + IG
```

1. **第一阶段**：NEH 生成高质量初始解
2. **第二阶段**：PSO 进行全局搜索
3. **第三阶段**：IG 进行局部深挖

### 3.2 核心流程

```python
# 1. 创建环境
env = HFSPEnvironment(n_jobs, n_stages, machines_per_stage)

# 2. 创建 IG 算法
ig = IteratedGreedy(
    destruction_ratio=0.3,
    reconstruction_method='greedy',
    acceptance_criterion='non_deteriorating',
    max_iterations=15
)

# 3. 创建 PSO 算法
pso = NichingPSO(
    env=env,
    population_size=100,
    max_generations=200,
    w=0.7,
    c1=1.5,
    c2=1.5,
    k_neighbors=3,
    stagnation_threshold=10
)

pso.set_ig_algorithm(ig)

# 4. 运行优化
best_fitness, best_position, multimodal_solutions = pso.run()

# 5. 创建档案库
archive = MultimodalArchive(
    makespan_tolerance=0.01,
    permutation_distance_threshold=3,
    machine_assignment_threshold=1
)

# 6. 添加解
for sol in multimodal_solutions:
    archive.add_solution(
        permutation=sol['permutation'],
        makespan=sol['makespan'],
        machine_assignments=sol['machine_assignments']
    )

# 7. 使用 IG 进一步挖掘
ig_solutions = ig.find_multimodal_solutions(best_position, env, n_solutions=5)
for sol in ig_solutions:
    archive.add_solution(
        permutation=sol['permutation'],
        makespan=sol['makespan'],
        machine_assignments=sol['machine_assignments']
    )
```

## 8. 算法流程图

### 8.1 NEH 启发式算法流程图

```mermaid
flowchart TD
    A[开始] --> B[计算每个工件的总加工时间<br/>T_j = Σ_k Σ_m p_jkm / m_k]
    B --> C[按总加工时间降序排序<br/>T_1 ≥ T_2 ≥ ... ≥ T_n]
    C --> D[初始化空排列<br/>current_permutation = []]
    D --> E[对每个工件 j in sorted_jobs]
    E --> F[尝试将工件插入到每个可能位置<br/>for pos in 0..len(current)]
    F --> G[计算新排列的 Makespan<br/>new_perm = current[:pos] + [j] + current[pos:]<br/>makespan = evaluate(new_perm)]
    G --> H{makespan < best?}
    H -->|是| I[更新最优值<br/>best = makespan, best_pos = pos]
    H -->|否| J[跳过]
    I --> K[插入到最优位置<br/>current = current[:best_pos] + [j] + current[best_pos:]]
    J --> K
    E --> K
    K --> L{还有工件?}
    L -->|是| E
    L -->|否| M[返回最优解<br/>return current_permutation, best_makespan]
    M --> N[结束]
```

### 8.2 PSO 算法流程图

```mermaid
flowchart TD
    A[开始] --> B[初始化种群<br/>├─ NEH 初始化 前5个粒子<br/>├─ SPT 初始化 前5个粒子<br/>└─ 随机初始化 剩余粒子]
    B --> C[构建环形拓扑<br/>每个粒子只与左右k个邻居交互]
    C --> D[开始迭代<br/>for gen in rangemax_generations)]
    D --> E[更新自适应权重<br/>w = w_max - w_max-w_min) × gen/max_gen]
    E --> F[更新小生境结构<br/>构建环形拓扑]
    F --> G[对每个粒子 i in population]
    G --> H[获取局部最优<br/>local_best = get_local_besti)]
    H --> I[更新粒子速度<br/>v = w×v + c1×r1×pbest-x + c2×r2×lbest-x]
    I --> J[更新粒子位置<br/>x = x + v 使用交换操作]
    J --> K[评估粒子适应度<br/>fitness = evaluateparticle)]
    K --> L[更新个体最优<br/>if fitness < pbest_fitness]
    L --> M[更新局部最优<br/>if fitness < local_best_fitness]
    M --> N[更新全局最优<br/>if fitness < global_best_fitness]
    N --> O[检查停滞<br/>if stagnation_detector.check_stagnationi)]
    O --> P{停滞?}
    P -->|是| Q[重新初始化粒子<br/>reinitializeparticle)]
    P -->|否| R[跳过]
    Q --> S[应用变异<br/>if random < mutation_prob]
    R --> S
    S --> T{还有粒子?}
    T -->|是| G
    T -->|否| U[输出结果<br/>best_fitness, best_position, multimodal_solutions]
    U --> V[结束]
```

```mermaid
    D --> E[2. 重建阶段<br/>for job in destroyed_jobs:<br/>for pos in 0..lenremaining):<br/>candidate = remaining[:pos] + [job] + remaining[pos:]<br/>makespan = evaluatecandidate]
    E --> F[3. 评估新解<br/>new_makespan = evaluate(new_permutation)]
    F --> G[4. 接受准则<br/>if new_makespan <= current_makespan:<br/>accept<br/>else if exp-new-current)/T > random:<br/>accept]
    G --> H[5. 更新最优<br/>if new_makespan < best_makespan:<br/>best = new]
    H --> I[6. 降温<br/>T = T × cooling_rate]
    I --> J[输出结果<br/>best_permutation, best_makespan]
    J --> K[结束]
```
