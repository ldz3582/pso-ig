# HFSP 项目开发文档（完整版）

## 1. 项目概述

本项目实现了一个面向混合流水车间调度问题（HFSP, Hybrid Flow Shop Scheduling）的智能求解与可视化系统。系统覆盖了算例输入、算法求解、结果分析、多解档案管理以及动态甘特图展示，支持基础 `PSO + IG` 求解与多智能体协同求解两种模式。

项目目标包括：

- 实现技术文档中的 HFSP 求解流程
- 提供可运行的 Web 交互系统
- 支持 benchmark 导入、本地 JSON 导入与手工输入算例
- 支持结果分析和动态可视化展示

## 2. 技术架构

系统整体采用前后端一体化结构：

- 前端：原生 `HTML + CSS + JavaScript`
- 后端：`FastAPI`
- 服务启动：`Uvicorn`
- 算法核心：Python 实现的 HFSP 环境、PSO、IG、小生境机制、多模态档案

整体分层如下：

1. `web/`：前端页面、样式、交互逻辑
2. `src/web_app.py`：Web API 与静态资源入口
3. `src/*.py`：求解器、环境解码、分析模块
4. `benchmarks/`：测试算例
5. `output/`、`results/`：结果输出与实验产物

### 3.1 Python 侧

- `FastAPI`

  - 结果分析统计

### 3.2 前端侧

- `HTML`
  - 组织多页面工作台结构
- `CSS`
  - 构建苹果风玻璃质感、单屏工作区、动态甘特图界面
- `JavaScript`
  - 算例编辑、接口调用、结果渲染、动态甘特图播放控制

- `start_hfsp_web.bat`

## 4. 核心算法实现

### 4.1 HFSP 环境建模

核心文件：

- [hfsp_environment.py](D:\codeworks\gfspn\HFSP\src\hfsp_environment.py)

实现内容：

- HFSP 算例表示
- 工件排列和机器分配的解码
- 调度结果评估
- `makespan` 计算
- 调度操作序列输出，供分析与甘特图使用

### 4.2 基础算法：Niching PSO + Iterated Greedy

核心文件：

- [niching_pso.py](D:\codeworks\gfspn\HFSP\src\niching_pso.py)
- [iterated_greedy.py](D:\codeworks\gfspn\HFSP\src\iterated_greedy.py)
- [niching_mechanism.py](D:\codeworks\gfspn\HFSP\src\niching_mechanism.py)

实现内容：

- 粒子群初始化与更新
- 小生境机制，避免种群早熟
- IG 破坏与重建局部优化
- 多模态候选解保留

### 4.3 多智能体协同求解

核心文件：

- [multimodal_hfsp_solver.py](D:\codeworks\gfspn\HFSP\src\multimodal_hfsp_solver.py)

实现内容：

- `basic_pso_ig` 模式
- `multi_agent` 模式
- `compare` 对比模式

多智能体模式中，系统使用多类角色协同产生候选解并进行强化，逻辑上包含：

- 初始种子构造
- 局部强化
- 扩展探索
- 重点强化

### 4.4 多模态档案库

同样位于：

- [multimodal_hfsp_solver.py](D:\codeworks\gfspn\HFSP\src\multimodal_hfsp_solver.py)

实现内容：

- 判断新解是否具有新颖性
- 依据 `makespan`、排列距离、机器分配差异保留多样化解
- 输出档案数据供前端分析展示

## 6. Web 系统实现

核心文件：
